# 🍽️ MESS MATE @ UH

> **Know What's on Your Plate.**

🌐 **Live App:** [krishilink-production.up.railway.app/app.html](https://krishilink-production.up.railway.app/app.html)

**MESS MATE @ UH** is a modern, mobile-first mess menu platform built for **United Homes (UH)**, the off-site hostel of **Karnavati University**.

It helps students quickly find **what is actually being served**, while clearly distinguishing between the planned monthly menu and the confirmed menu for the day.

---

## ✨ Features

### 👨‍🎓 For Students

* **Today's Live Menu** — See what's being served right now, what's coming up, and what's already ended.
* **Calendar View** — Browse the full week's menu using a swipeable date selector.
* **Favourite Dishes** — Save favourite dishes and get alerts when they're on the menu.
* **Planned vs Confirmed Menu** — Easily identify whether a menu is planned or officially confirmed.
* **Meal Timings** — Quickly check breakfast, lunch, snacks, and dinner timings.
* **Last Updated** — See when the menu was most recently updated.
* **Dark Mode** — Switch between light and dark themes.
* **PWA / Home Screen** — Install MESS MATE directly on your phone's home screen for quick access.

### 👨‍🍳 For Mess Administration

* **Quick Menu Updates** — Update the current day's menu in seconds.
* **Real-Time Sync** — Changes are reflected instantly for students.
* **Menu Status** — Mark meals as Planned or Confirmed.
* **Menu Editing** — Modify food items whenever the actual menu changes.
* **Upcoming Menu** — Prepare menus for upcoming days.

---

## 🎯 The Problem

Hostel messes usually provide a monthly menu in the form of an image or printed schedule.

The problem is that the **actual menu often doesn't follow the planned menu exactly**.

Students therefore don't always know what food is actually being served until they reach the mess.

### MESS MATE solves this by separating:

**📅 Planned Menu**
What was originally scheduled.

**🟢 Confirmed Menu**
What the mess has actually confirmed and will serve.

This makes the information more reliable and useful for students.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/MESSMATE.git
```

Navigate into the project:

```bash
cd MESSMATE
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will be available at the local development URL shown in your terminal.
